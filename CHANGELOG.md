# Novidades

## 1.2.0
- **Instalar IA local pra mim**: o Bitu instala o Ollama, baixa o modelo e, se você quiser, instala e configura o OpenClaw sozinho (instaladores oficiais), mostrando o progresso de cada etapa.
- **Voz e microfone offline**: um clique baixa o Piper (voz em português) e o whisper.cpp (entende a sua fala). Funciona sem internet e sem conta.
- **Camisa de time**: modelos (lisa, listrada, faixa, meio a meio, xadrez, gola), cores e número; combinações prontas. O Bitu comemora quando você escreve "gol".
- Microfone escolhe sozinho entre offline e OpenAI.
- Página do projeto nova, com banner, prints e botões.

## 1.1.0
- **Modo 100% local**: o Bitu agora conversa com o OpenClaw, o Ollama, o LM Studio ou qualquer servidor compatível com a API da OpenAI rodando no PC. Não precisa de Claude nem ChatGPT.
- Botão **Procurar no meu PC**: acha os servidores abertos, lê o token do OpenClaw sozinho e liga a API de chat do OpenClaw com um clique.
- Se o modelo local não aceitar ferramentas, o Bitu continua conversando normalmente.
- Opção de dizer se o modelo enxerga imagens (para ver a tela).
